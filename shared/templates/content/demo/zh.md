# 欢迎使用 markoto

你输入 Markdown，预览会显示它排出来的页面，导出的 PDF 一模一样。在宽屏上预览位于右侧，在手机上则在顶部的眼睛图标里。这份演示先介绍 Markdown 的基本写法，再介绍 markoto 额外提供的功能。随便改，不用担心。

## 试一试

在方括号之间输入 `x` 即可勾选。

- [ ] **分享。** 右上角的锁形图标（或 **分享 → 分享设置…**）决定拿到链接的人能做什么：“私有 — 仅你自己”“任何人可查看”“任何人可编辑”或“密码保护”。
- [ ] **更换外观。** 右侧的调色板图标会打开 **文档主题**：预设、字体、颜色、页面尺寸、页眉和页脚。
- [ ] **编辑封面。** 这份文档以封面开头。在主题面板的 **封面页** 中可以设置版式、副标题、日期和作者，也可以关闭封面。
- [ ] **添加评论。** 选中一段文字，点击 **添加评论**。在评论里写 `@markoto`，AI 会在讨论串中回复。
- [ ] **问问 AI。** 点击底部的输入栏（“向 markoto 提问…”），试试“把上面的列表改成表格”。AI 会像协作者一样编辑文档，你能看着它打字。
- [ ] **用说的代替打字。** 工具栏里的麦克风用于听写，AI 输入栏里的麦克风可以接收语音请求。
- [ ] **回到过去。** 右侧的 **活动** 面板列出每一次修改。打开一条可以查看改了什么，或点击 **还原** 回到那个时间点（还原本身也可以撤销）。
- [ ] **导出 PDF。** **文件 → 导出 → PDF**，或按 Cmd/Ctrl + P 打印。
- [ ] **把资料交给 AI。** 在工作区的 **知识库** 中上传 PDF、Word 文件或幻灯片，该工作区文档里的 AI 会在其中查找答案。

> [!NOTE]
> AI、`@markoto` 和工作区需要账号。请在右上角 **登录**。

## 链接

[一个链接](https://commonmark.org/help/) 会在新标签页中打开。像 https://commonmark.org 这样的网址会自动变成链接。

## 引用

## 代码

行内 `代码` 用反引号包起来。代码块带有语法高亮：

```python
def greet(name):
    return f"你好，{name}！"
```
