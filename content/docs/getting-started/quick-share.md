# Write & share your first document

You don't need an account to write something quickly in markoto. Open
the homepage, start writing, copy the link, and you're ready to send
it to anyone — they'll see whatever you typed, in real time.

This walkthrough takes about three minutes. By the end you'll have a
named document and a shareable URL on your clipboard.

::flow{id="quick-share" hide-title}
::

## What just happened

Anonymous documents start in **open-edit** mode by default — anyone
with the link can read AND edit. That's the fastest way to draft
something with a single collaborator: paste the link, both of you
type, both of you see each other's edits live.

To give someone view-only access, or to lock the document behind a
password, sign in before you create it: the owner of a document gets
those options in the same share dialog. Anonymous documents always stay
open-edit. See [Lock a document behind a password](/docs/sharing/password-protect)
for the password flow.
