# Get started

markoto is a collaborative markdown editor with optional accounts. You
can write a document anonymously, share it by URL, change how it
looks and export it to PDF, all without signing up.

## The starter tutorials

- [**Write & share your first document**](/docs/getting-started/quick-share): Create a doc, name it, and send the link. ~3 minutes.
- [**Start from a template**](/docs/getting-started/templates): Skip the blank page; pick a shape that matches your project.
- [**Turn your draft into a polished PDF**](/docs/import-export/polished-pdf): Pick a theme, hit Save as PDF, get a polished file.
- [**Bring an existing Word or PDF document in**](/docs/import-export/import-existing): Start from what you already have.

## After that

When you're comfortable with the basics:

- [**Write**](/docs/writing): the [markdown reference](/docs/writing/markdown-reference),
  rich content, voice dictation.
- [**AI assistant**](/docs/ai): what each AI feature needs
  ([overview](/docs/ai/overview)), and how to
  [connect your own provider](/docs/ai/provider).
- [**Collaborate**](/docs/collaborate): write together live, discuss in comments.
- [**Share and publish**](/docs/sharing): read-only and password-protected
  links, QR codes, publishing as a web page.
- [**Design**](/docs/themes): themes, presets, cover pages.
- [**Import, export and history**](/docs/import-export): DOCX/PDF/PPTX/XLSX/HTML/EPUB
  in; Markdown + PDF out; see every change and restore any past version.
- [**Workspaces**](/docs/workspaces): team-shared docs with roles and guests.
- [**Workspace administration**](/docs/workspace-admin): brand kit, single
  sign-on, audit log.
- [**Plans and billing**](/docs/plans): the free tier, paid plans, AI Points.
- [**Account and privacy**](/docs/account): sign out everywhere, export
  your data, delete your account.
- [**Run markoto yourself**](/docs/self-hosting): install markoto on
  your own server.
