# Set a default theme for your workspace

Once your team has tuned a theme that matches your brand, set it as
the workspace default. Every blank doc anyone creates inside the
workspace starts with that theme already applied. Templates bring a
design of their own, and members can switch any doc to another theme;
the default is the starting point, not a constraint.

::flow{id="set-a-default-theme-for-your-workspace" hide-title}
::

## What just happened

Workspace admins pick the default theme on the workspace settings page,
from the built-in presets and their own saved presets. From then on,
**Blank** in the new-document dialog is a page in that theme, and the
dialog names it ("Blank · Corporate report"). A template other than
Blank keeps the design it was written for.

Existing docs aren't retroactively re-themed. The workspace default
applies only to docs created AFTER it was set.
