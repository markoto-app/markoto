# Workspaces

A workspace is a shared home for documents, members, themes, and
optionally an uploaded knowledge base the AI can read from. Three
roles — **admin**, **editor**, **viewer** — gate who can edit, manage
access, or invite members.

- [Start a workspace](/docs/workspaces/start) — create one, name it, set defaults.
- [Roles inside a workspace](/docs/workspaces/roles) — what admins, editors, and viewers can each do.
- [Invite a teammate](/docs/workspaces/invite) — invite by email; they join once they accept.
- [Two writers, one document](/docs/workspaces/live-collab) — live co-editing with awareness.
- [Plans](/docs/account/plans) — the Team plan (coming soon) covers a whole workspace, billed per seat.
- [Ask the AI about uploaded files](/docs/writing/knowledge-rag) — the workspace knowledge base.
- [Set a default theme for the workspace](/docs/workspaces/default-theme) — every new doc starts styled.
