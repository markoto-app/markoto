# Import, export and history

Bring existing documents into markoto without losing structure: DOCX,
PDF, PPTX, XLSX, HTML and EPUB all import as clean markdown. Export
goes the other way: a `.md` download or a PDF in the document's theme.

- [Bring an existing document in](/docs/import-export/import-existing): Word, PDF, HTML, more, converted to clean markdown.
- [Polish a document and download as PDF](/docs/import-export/polished-pdf): pick a theme, export the rendered PDF.
- [Save as Markdown](/docs/import-export/save-markdown): `.md` download for git, Obsidian, anywhere.

## History

markoto records every edit, theme change, and comment as an entry in
the activity log. Every entry also keeps the document as it was, so you
can see exactly what changed and restore the document to that point.

- [See what changed in past edits](/docs/import-export/see-changes): diff drawer with hunk-level highlights.
- [Restore an earlier version](/docs/import-export/restore): one click rolls the doc back, and the restore can itself be undone.
