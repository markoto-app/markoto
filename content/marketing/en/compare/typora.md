# markoto vs Typora

**Typora** is a desktop Markdown editor for macOS, Windows and Linux. It hides the Markdown syntax as you type, so the text looks formatted while it stays a plain `.md` file on your computer. You pay once and keep it.

**markoto** is a Markdown editor in the browser for documents that several people work on and that end up as pages. You see the Markdown on one side and printed pages on the other, people edit at the same time, and the PDF matches the preview.

If you write alone, on your own computer, Typora is hard to beat. If others need to edit, comment or read along without installing anything, markoto is built for that.

::

## Where Typora is better

- **Seamless editing.** Typora shows formatted text in a single pane, without a separate preview. In markoto you see the Markdown source, with the pages next to it.
- **A desktop app with local files.** Your documents are files on your disk: they work without a connection, sit in whatever folder or sync service you like, and open in any other editor. markoto stores documents on a server and needs a connection.
- **A one-time purchase.** $14.99 for up to three devices, no subscription.
- **More export formats.** HTML and images built in; Word, OpenOffice, LaTeX, ePub and more through Pandoc. markoto exports PDF and Markdown only.
- **Free page sizes.** Typora's PDF export takes a custom paper size. markoto offers A4, A5, Letter and Legal.
- **More diagram syntaxes.** flowchart.js and js-sequence besides Mermaid. markoto renders Mermaid only.
- **A large theme gallery.** Many community CSS themes to choose from.

## Where markoto is better

- **Collaboration.** Several people type in the same document at once and see each other's cursors. Comment threads stay anchored to the text, and every edit is kept with a diff and a restore button. Typora has no collaboration features of its own; you share files through a sync folder.
- **Nothing to install.** markoto opens in any browser, on any device, including a borrowed one. Anyone with the link can edit, without an account, if the owner allows it.
- **Pages as you write.** The preview shows A4 or Letter pages with page breaks where they will fall, a cover page and a table of contents with page numbers. In Typora you write in one continuous page and see the page layout in the exported PDF.
- **Print themes.** Built-in presets (including arXiv and two-column IEEE paper layouts) and a theme editor for fonts, colours, margins, columns, headers, footers and cover, without writing CSS.
- **Import from Office files.** markoto converts Word, PDF, PowerPoint, Excel, HTML and EPUB into Markdown without extra software.
- **AI assistant.** markoto's assistant edits the document, answers in comments and can use files uploaded to a workspace.
- **Free, or on your own server.** markoto.app has a free plan, and markoto is source-available and can be self-hosted.

## Who should pick which

Pick **Typora** if you write on your own, want your documents as local files, and like the text formatted as you type.

Pick **markoto** if others write or comment with you, if you want to see the pages while you write, or if you don't want to install anything.

## Moving between them

A Typora file is a Markdown file, so open it in markoto with **File › Import**, or paste the text into a new document. Headings, lists, tables, footnotes, math between dollar signs and Mermaid diagrams carry over; flowchart.js and js-sequence blocks stay as code. Images stored next to the file on your disk have to be uploaded again (drag them into the editor). To go back, download the document as Markdown and open it in Typora.

---
items:
  - q: Is there an online version of Typora?
    a: Typora is a desktop app for macOS, Windows and Linux. markoto is an alternative that runs in the browser, with live collaboration.
  - q: Can I collaborate in Typora?
    a: Typora has no co-editing of its own. People share files through Dropbox, iCloud or a similar sync folder. markoto lets several people edit the same document at once.
  - q: Does markoto work offline?
    a: No. markoto needs a connection. It keeps edits made during a short drop and sends them when the connection is back.
  - q: Is markoto free?
    a: Yes. markoto.app has a free plan, including PDF export and collaboration. Paid plans (Pro for one person, Team and Business per seat for a workspace) raise the limits. Self-hosting is free too.
  - q: Do I need an account?
    a: No. You can write, share and download a PDF without signing in. An account lets you own documents, use workspaces and use the AI assistant.
